# AISI0016: View created from a class that isn't a PXView

**Severity:** error

`createSingle` and `createCollection` build a view from a class that extends `PXView`. The usual mistake is passing
the extension class you just wrote instead. That class extends nothing, so the view ends up with no fields.

MuiLint follows the class's `extends` chain. It reports the view only when that chain ends somewhere other than
`PXView`. If the chain runs into a class it can't open, it says nothing.

## Wrong

```ts
export class SO301000_AISI {
    ExtraLines = createCollection(SOLine_AISI);
}

export interface SOLine_AISI extends SOLine {}
export class SOLine_AISI {
    UsrNote: PXFieldState;
}
```

## Right

```ts
export class SO301000_AISI {
    ExtraLines = createCollection(ExtraLine);
}

export class ExtraLine extends PXView {
    UsrNote: PXFieldState;
}
```

## Turning it off

Once, above the offending line:

```ts
// muilint-disable-next-line AISI0016
```

For the whole file, anywhere in it: `// muilint-disable AISI0016`. For a whole folder, in `.editorconfig`:

```ini
[*.ts]
dotnet_diagnostic.AISI0016.severity = none
```
