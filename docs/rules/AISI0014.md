# AISI0014: Half an extension

**Severity:** warning

A TypeScript extension is two declarations with the same name: an interface that extends the class you're extending,
and a class with what you add. With only one of them it compiles and adds nothing.

Reported: an empty `interface X extends Y {}` with no `class X`, and a class that extends nothing, declares views,
fields or actions, and has no interface. An interface with a body is a type of its own (a control config, say) and is
left alone, as is a plain helper class.

## Wrong

```ts
export interface SOLine_AISI extends SOLine {}
```

## Right

```ts
export interface SOLine_AISI extends SOLine {}
export class SOLine_AISI {
	UsrPriority: PXFieldState;
}
```

## Source

- [UI Customization Development: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_Customization_GeneralInfo.md): "In the TypeScript file of an extension, you define an interface that extends the screen class and a class with the same name the interface has."

## Turning it off

Once, above the offending line: `// muilint-disable-next-line AISI0014`. For the whole file: `// muilint-disable AISI0014`. For a
whole folder, in `.editorconfig`:

```ini
[*.ts]
dotnet_diagnostic.AISI0014.severity = none
```
