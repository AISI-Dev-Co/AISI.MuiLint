# AISI0023: Unclosed or stray Modern UI tag

**Severity:** error

A `qp-*`, `field`, `template` or `using` element that is opened and never closed, or a closing tag with nothing open
to close. HTML only closes standard elements for you, so an unclosed custom element swallows everything after it,
and a stray end tag is a sign that the nesting isn't what it looks like.

Acumatica's own 24R1 screens have five of these: a stray `</field>` in FS300100, FS300200 and FS305600, `"/qp-grid>"`
for `</qp-grid>` in PM506000, and an unclosed `qp-include` in SM200521.

## Wrong

```html
<qp-fieldset id="fsAISI" after="#fsColumnB-Order" view.bind="Document">
  <field name="UsrRoute"></field></field>
</qp-fieldset>
```

## Right

```html
<qp-fieldset id="fsAISI" after="#fsColumnB-Order" view.bind="Document">
  <field name="UsrRoute"></field>
</qp-fieldset>
```

## Source

- [HTML Standard: Custom elements](https://html.spec.whatwg.org/multipage/custom-elements.html): custom elements are never void, so only their end tag closes them.

## Turning it off

Once, above the offending line: `<!-- muilint-disable-next-line AISI0023 -->`. For the whole file, anywhere in it:
`<!-- muilint-disable AISI0023 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0023.severity = none
```
