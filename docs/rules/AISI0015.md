# AISI0015: Decorator names an unknown view

**Severity:** warning

Some decorators name a view in a string: `primaryView` in `@graphInfo`, and `view` in `@handleEvent`. A string is
never checked by the compiler, so a typo there compiles fine. The primary view, or the event handler, then points at
nothing.

MuiLint checks those names against the views the screen's TypeScript declares, the same way
[AISI0011](AISI0011.md) does for the HTML. It stays quiet when it can't find the screen class.

## Wrong

```ts
@graphInfo({ graphType: "AISI.Shipping.ShipmentInquiry", primaryView: "Filtre" })
export class XX301000 extends PXScreen {
    Filter = createSingle(ShipmentFilter);
}
```

## Right

```ts
@graphInfo({ graphType: "AISI.Shipping.ShipmentInquiry", primaryView: "Filter" })
export class XX301000 extends PXScreen {
    Filter = createSingle(ShipmentFilter);
}
```

## Turning it off

Once, above the offending line:

```ts
// muilint-disable-next-line AISI0015
```

For the whole file, anywhere in it: `// muilint-disable AISI0015`. For a whole folder, in `.editorconfig`:

```ini
[*.ts]
dotnet_diagnostic.AISI0015.severity = none
```
