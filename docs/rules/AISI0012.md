# AISI0012: qp-* control without an id

**Severity:** suggestion

Customizations target controls by `#id`, and a control without one can only be reached through its neighbours.
Controls Acumatica doesn't give ids are exempt (`qp-field`, `qp-label`, `qp-include`, `qp-address-lookup`,
`qp-hyper-icon`, `qp-caption` and AcuMate's list), as is an id given through `config.bind="{id: '...'}"`.

## Flagged

```html
<qp-grid after="#fsColumnB-Order" view.bind="Transactions"></qp-grid>
```

## Fine

```html
<qp-grid id="gridAISI" after="#fsColumnB-Order" view.bind="Transactions"></qp-grid>
```

## Source

- [Form Layout: Predefined Templates](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_DesigningLayout_Templates.md): id "Identifies a template instance and can be used to reference the template in customizations and extensions".
- [UI Definition in HTML and TypeScript: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_UIDefinition_GeneralInfo.md): "id: An identifier of the control, which is a shortcut for the id property of the config attribute."

## Turning it off

Once, above the offending line: `<!-- muilint-disable-next-line AISI0012 -->`. For the whole file, anywhere in it:
`<!-- muilint-disable AISI0012 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0012.severity = none
```
