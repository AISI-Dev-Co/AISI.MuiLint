# AISI0005: Empty qp-fieldset

**Severity:** error · **Quick fix:** Ctrl+. → **Remove the empty qp-fieldset**

A `qp-fieldset` with nothing but whitespace or comments inside merges as an empty box with a caption and no fields.
Usually it's a leftover from moving fields elsewhere.

Fieldsets that carry `modify`, `remove` or `replace` are fine empty: they act on an existing fieldset rather than
adding a new one.

## Wrong

```html
<qp-fieldset id="fsColumnC-AISI" after="#fsColumnB-Order" view.bind="Document">
  <!-- TODO -->
</qp-fieldset>
```

## Right

```html
<qp-fieldset id="fsColumnC-AISI" after="#fsColumnB-Order" view.bind="Document">
  <field name="UsrDeliveryWindow"></field>
</qp-fieldset>

<!-- Allowed: changes an existing fieldset -->
<qp-fieldset modify="#fsColumnA-Order" caption="Order"></qp-fieldset>
```

## Turning it off

Once, above the offending line:

```html
<!-- muilint-disable-next-line AISI0005 -->
```

For the whole file, anywhere in it: `<!-- muilint-disable AISI0005 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0005.severity = none
```
