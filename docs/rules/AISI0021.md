# AISI0021: Unknown config.bind key

**Severity:** warning

`config.bind` takes an object of the control's configuration (`IGridConfig` for `qp-grid`, and so on). A key that the
control's configuration interface doesn't define is ignored. Only object literals written in the HTML are checked,
and only for controls whose configuration interface is fully known: one with an index signature, a union or an
unreadable base type is skipped.

## Wrong

```html
<qp-grid id="grid-AISI" view.bind="Transactions" config.bind="{ alowInsert: false }"></qp-grid>
```

## Right

```html
<qp-grid id="grid-AISI" view.bind="Transactions" config.bind="{ allowInsert: false }"></qp-grid>
```

## Where the answer comes from

The list comes from the site's own `node_modules/client-controls` (or `@acumatica/client-controls`) package, beside
the `src` folder the file is in, so it matches the Acumatica version you build against. With no package there, the
rule stays quiet.

## Source

- [Menu: Configuration of the Menu Control](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDevRef_Menu_Options.md): "In the HTML template, specify the property or the method in the config.bind property of the qp-menu control."

## Turning it off

Once, above the offending line: `<!-- muilint-disable-next-line AISI0021 -->`. For the whole file, anywhere in it:
`<!-- muilint-disable AISI0021 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0021.severity = none
```
