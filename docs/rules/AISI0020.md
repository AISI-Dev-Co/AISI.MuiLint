# AISI0020: Unknown qp-template name

**Severity:** warning

The `name` of a `<qp-template>` picks one of the predefined layouts (`17-17-14`, `7-10-7`, `record-1`, ...). A name that
isn't one of them gives you no layout.

## Wrong

```html
<qp-template id="form-AISI" name="17-17-41"></qp-template>
```

## Right

```html
<qp-template id="form-AISI" name="17-17-14"></qp-template>
```

## Where the answer comes from

The list comes from the site's own `node_modules/client-controls` (or `@acumatica/client-controls`) package, beside
the `src` folder the file is in, so it matches the Acumatica version you build against. With no package there, the
rule stays quiet.

## Source

- [Form Layout: Predefined Templates](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_DesigningLayout_Templates.md): "You specify a template by using the qp-template tag with the following required attributes: ... name: Specifies which template to use."

## Turning it off

Once, above the offending line: `<!-- muilint-disable-next-line AISI0020 -->`. For the whole file, anywhere in it:
`<!-- muilint-disable AISI0020 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0020.severity = none
```
