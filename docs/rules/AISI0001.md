# AISI0001: Self-closing Modern UI tag

**Severity:** error

`<field .../>`, `<qp-grid .../>` and the like aren't allowed. HTML only lets a few standard tags close themselves; a
custom tag written that way stays open, and whatever follows it ends up inside it.

## Wrong

```html
<field name="UsrPriority" after="#fsColumnA-Order [name='OrderDate']"/>
```

## Right

```html
<field name="UsrPriority" after="#fsColumnA-Order [name='OrderDate']"></field>
```

The lightbulb adds the closing tag for you.

## Source

- [UI Definition in HTML and TypeScript: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_UIDefinition_GeneralInfo.md): "You can't use shortened versions of custom HTML tags, such as `<qp-grid .../>` or `<qp-button .../>`. An HTML limitation prohibits shortened version of tags except for a limited number of standard HTML tags."

## Turning it off

Once, above the offending line: `<!-- muilint-disable-next-line AISI0001 -->`. For the whole file, anywhere in it:
`<!-- muilint-disable AISI0001 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0001.severity = none
```
