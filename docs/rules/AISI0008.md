# AISI0008: Duplicate field name or id

**Severity:** warning

The same id or the same field twice in one container. A selector for it matches both, and the Modern UI build fails
on a selector that matches more than one element.

Only repeats within one container are reported, because Acumatica's own screens repeat ids like `btnOK` across dialogs
and show a field in two places of a view (`CuryTaxTotal` in AP301000).

## Wrong

```html
<qp-fieldset id="fsAISI" after="#fsColumnA-Order" view.bind="Document">
  <field name="UsrPriority"></field>
  <field name="UsrPriority"></field>
</qp-fieldset>
```

## Source

- [Reusing of UI Definitions: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_UIDefinitionReuse_GeneralInfo.md): "If more than one item satisfies the specified CSS selector, the build process fails."

## Turning it off

Once, above the offending line: `<!-- muilint-disable-next-line AISI0008 -->`. For the whole file, anywhere in it:
`<!-- muilint-disable AISI0008 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0008.severity = none
```
