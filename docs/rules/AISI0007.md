# AISI0007: retired

This rule reported extension HTML with no `.ts` of the same name beside it, claiming the HTML would never be merged.
Acumatica's own screens disprove it: 24R1 ships dozens of HTML-only extensions, such as
`CR301000/extensions/CR301000_tab_General.html`. An extension that only rearranges the layout needs no TypeScript.

Fields such an extension uses are still checked, against the screen as its other files declare it (AISI0011). The id
won't be reused; a `muilint-disable` comment or `.editorconfig` line naming it does nothing now.
