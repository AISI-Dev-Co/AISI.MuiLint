# AISI0006: Malformed merge selector

**Severity:** error

The value of `after`, `before`, `append`, `prepend`, `modify`, `remove` or `replace` is a CSS selector. One with an
unclosed `[`, `(` or quote isn't valid, and the Modern UI build fails on a selector that doesn't match exactly one
element.

## Wrong

```html
<field name="UsrCarrier" after="[name='CustomerID'"></field>
```

## Right

```html
<field name="UsrCarrier" after="[name='CustomerID']"></field>
```

## Source

- [Reusing of UI Definitions: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_UIDefinitionReuse_GeneralInfo.md): lists the seven attributes and says "If no element satisfies the CSS selector, the build process fails" and "If more than one item satisfies the specified CSS selector, the build process fails."

## Turning it off

Once, above the offending line: `<!-- muilint-disable-next-line AISI0006 -->`. For the whole file, anywhere in it:
`<!-- muilint-disable AISI0006 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0006.severity = none
```
