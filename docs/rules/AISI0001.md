# AISI0001: Self-closing Modern UI tag

**Severity:** error · **Quick fix:** Ctrl+. → **Add the closing tag**

Modern UI tags are custom elements, and HTML has no self-closing custom elements. `<field name="X"/>` isn't a
complete field: the parser treats it as an opening tag and happily swallows whatever comes next as its children. The
merge then either nests your markup somewhere odd or drops it.

## Wrong

```html
<field name="UsrPriority" after="[name='OrderDate']"/>
<qp-grid id="grid-Lines" view.bind="Transactions" />
```

## Right

```html
<field name="UsrPriority" after="[name='OrderDate']"></field>
<qp-grid id="grid-Lines" view.bind="Transactions"></qp-grid>
```

Comments are ignored, so a commented-out `<field/>` won't trip it.

## Turning it off

Once, above the offending line:

```html
<!-- muilint-disable-next-line AISI0001 -->
```

For the whole file, anywhere in it: `<!-- muilint-disable AISI0001 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0001.severity = none
```
