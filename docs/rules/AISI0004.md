# AISI0004: Extension named as the parent screen

**Severity:** error

An extension of `SO301000` is `SO301000_Something.html`. A file called `SO301000.html` inside `SO301000/extensions`
looks like the screen itself to the build, which is not what you meant. Add a suffix (your company prefix is the usual
choice) and rename the matching `.ts` to the same name.

## Wrong

```text
SO301000/extensions/SO301000.html
```

## Right

```text
SO301000/extensions/SO301000_AISI.html
```

## Turning it off

This is about the file itself, so it's switched off per file, with `<!-- muilint-disable AISI0004 -->` anywhere in it, or per folder in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0004.severity = none
```
