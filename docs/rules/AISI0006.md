# AISI0006: Malformed merge selector

**Severity:** error

The value of `after`, `before`, `append`, `prepend`, `modify`, `remove` or `replace` is a CSS selector. If a bracket,
parenthesis or quote is left open, the selector can't match anything and the merge skips your element.

The classic way to get here is using the same quote inside the selector as around the attribute, which ends the
attribute early: `after="[name="OrderDate"]"` is really `after="[name="`.

## Wrong

```html
<field name="UsrPriority" after="[name='OrderDate'"></field>
<field name="UsrRush" before="[name="CustomerID"]"></field>
```

## Right

```html
<field name="UsrPriority" after="[name='OrderDate']"></field>
<field name="UsrRush" before="[name='CustomerID']"></field>
```

## Turning it off

Once, above the offending line:

```html
<!-- muilint-disable-next-line AISI0006 -->
```

For the whole file, anywhere in it: `<!-- muilint-disable AISI0006 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0006.severity = none
```
