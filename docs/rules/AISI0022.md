# AISI0022: Unknown control-type

**Severity:** warning

`control-type` on a `field` swaps the editor for another control, named by its tag (`qp-barcode-input`,
`qp-check-box`, ...). A `qp-` name that isn't a control does nothing.

## Wrong

```html
<field name="Barcode" control-type="qp-barcode-imput"></field>
```

## Right

```html
<field name="Barcode" control-type="qp-barcode-input"></field>
```

## Where the answer comes from

The list comes from the site's own `node_modules/client-controls` (or `@acumatica/client-controls`) package, beside
the `src` folder the file is in, so it matches the Acumatica version you build against. With no package there, the
rule stays quiet.

## Source

- [Barcode Editor: Conversion from ASPX to HTML and TypeScript](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDevRef_BarcodeInput_ASPX.md): "Replace it with field and specify `control-type="qp-barcode-input"` in the field tag."

## Turning it off

Once, above the offending line: `<!-- muilint-disable-next-line AISI0022 -->`. For the whole file, anywhere in it:
`<!-- muilint-disable AISI0022 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0022.severity = none
```
