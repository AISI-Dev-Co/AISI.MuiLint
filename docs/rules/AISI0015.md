# AISI0015: Decorator names an unknown view

**Severity:** warning

`primaryView` in `@graphInfo`, or the view argument of `@handleEvent`, names a view the screen doesn't declare. The
backend matches view names case-insensitively, so `primaryView: 'filter'` for a `Filter` view is fine.

## Wrong

```ts
@handleEvent(CustomEventType.RowSelected, { view: "Transaction" })
```

## Right

```ts
@handleEvent(CustomEventType.RowSelected, { view: "Transactions" })
```

## Source

- [UI Definition in HTML and TypeScript: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_UIDefinition_GeneralInfo.md): the screen class "has the graphInfo decorator, in which you specify the graph and its primary view."
- [Activity 7.2.1: To Implement and Debug an Event Handler](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_HandlingEvents_DefineAndDebug_Activity.md): the second parameter is "the view for which the event handler is intended".

## Turning it off

Once, above the offending line: `// muilint-disable-next-line AISI0015`. For the whole file: `// muilint-disable AISI0015`. For a
whole folder, in `.editorconfig`:

```ini
[*.ts]
dotnet_diagnostic.AISI0015.severity = none
```
