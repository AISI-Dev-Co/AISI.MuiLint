# AISI0005: Empty qp-fieldset

**Severity:** suggestion

A `qp-fieldset` with nothing in it that nothing later in the file adds to. Usually something was meant to go in it.

Acumatica's own screens leave some fieldsets empty on purpose, so these are skipped: hidden ones (`class="hidden"`),
`wg-container` ones, and ones with `modify`/`remove`/`replace`.

## Flagged

```html
<qp-fieldset id="fsAISI" after="#fsColumnB-Order" view.bind="Document"></qp-fieldset>
```

## Fine

```html
<qp-fieldset id="fsAISI" after="#fsColumnB-Order" view.bind="Document"></qp-fieldset>
<field append="#fsAISI" name="UsrPriority"></field>
```

## Source

- [UI Adjustments in HTML and TypeScript: HTML Examples](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_AdjustmentInExtension_HTML.md): the docs have no rule against empty fieldsets, so this is only a suggestion.

## Turning it off

Once, above the offending line: `<!-- muilint-disable-next-line AISI0005 -->`. For the whole file, anywhere in it:
`<!-- muilint-disable AISI0005 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0005.severity = none
```
