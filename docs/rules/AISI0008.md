# AISI0008: Duplicate field name or id

**Severity:** warning

Ids have to be unique in a page, and merge selectors only ever find the first match. Two elements with
`id="fsColumnC-AISI"` means the second one can never be targeted, and any later extension that uses `#fsColumnC-AISI`
gets whichever came first.

For fields the check is per view: the same field in the same `view.bind` twice is almost always a copy-and-paste slip.
The same field name in two different views (`Status` on `Document` and on `CurrentDocument`) is fine and isn't reported.
Elements that `modify` or `remove` something are skipped, because their id and name refer to the existing element.

## Wrong

```html
<qp-fieldset id="fsColumnC-AISI" after="#fsColumnB-Order" view.bind="Document">...</qp-fieldset>
<qp-fieldset id="fsColumnC-AISI" after="#fsColumnA-Order" view.bind="Document">...</qp-fieldset>
```

## Right

```html
<qp-fieldset id="fsColumnC-AISI" after="#fsColumnB-Order" view.bind="Document">...</qp-fieldset>
<qp-fieldset id="fsColumnD-AISI" after="#fsColumnA-Order" view.bind="Document">...</qp-fieldset>
```

## Turning it off

Once, above the offending line:

```html
<!-- muilint-disable-next-line AISI0008 -->
```

For the whole file, anywhere in it: `<!-- muilint-disable AISI0008 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0008.severity = none
```
