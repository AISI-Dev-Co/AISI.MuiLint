# AISI0013: Malformed config.bind

**Severity:** error

`config.bind` takes an expression, usually an object literal: `config.bind="{imageSet: 'main', imageKey: 'Refresh'}"`.
One with an unclosed `{`, `[`, `(` or quote isn't a valid expression.

## Wrong

```html
<qp-grid id="gridAISI" view.bind="Transactions" config.bind="{ allowInsert: false"></qp-grid>
```

## Right

```html
<qp-grid id="gridAISI" view.bind="Transactions" config.bind="{ allowInsert: false }"></qp-grid>
```

## Source

- [UI Definition in HTML and TypeScript: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_UIDefinition_GeneralInfo.md): shows `config.bind="{imageSet: 'main', imageKey: 'Refresh'}"`.

## Turning it off

Once, above the offending line: `<!-- muilint-disable-next-line AISI0013 -->`. For the whole file, anywhere in it:
`<!-- muilint-disable AISI0013 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0013.severity = none
```
