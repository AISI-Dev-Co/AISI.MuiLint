# AISI0017: Extension outside an extensions folder

**Severity:** warning

A file under `development/screens` or `customizationScreens` named like an extension of its screen
(`SO301000/SO301000_AISI.html`) that isn't in the screen's `extensions` folder, where Acumatica keeps extensions.

Only the name counts. A screen of your own that reuses another through `qp-include` uses `after`, `append` and the
rest too, so merge attributes prove nothing.

## Wrong

```text
SO301000/
  SO301000_AISI.html
  SO301000_AISI.ts
```

## Right

```text
SO301000/
  extensions/
    SO301000_AISI.html
    SO301000_AISI.ts
```

## Source

- [Modern UI Development: Creating Modern UI Source Files for Custom and Customized Forms](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_ModernUI_DevelopmentFolder.md): "For customized forms, the HTML and TypeScript files are stored in the `extensions` folder".
- [Reusing of UI Definitions: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_UIDefinitionReuse_GeneralInfo.md): a screen that includes another adjusts it with `after`, `append` and the rest.

## Turning it off

This one is about the file itself, so it's switched off per file: `<!-- muilint-disable AISI0017 -->` in HTML (or
`// muilint-disable AISI0017` in TypeScript), anywhere in it. Or per folder in `.editorconfig`:

```ini
[*.{html,ts}]
dotnet_diagnostic.AISI0017.severity = none
```
