# AISI0017: Extension outside an extensions folder

**Severity:** error

The build only merges extension files from the screen's `extensions` folder. An extension saved anywhere else, say
beside the screen in `SO301000/` instead of `SO301000/extensions/`, is never merged. Nothing tells you; your field just
isn't there.

MuiLint checks `.html` and `.ts` files under `development/screens` and `customizationScreens` that aren't in an
`extensions` folder. It reports one that:

- is named like an extension of the folder it's in (`SO301000/SO301000_AISI.html`);
- in HTML, uses a merge attribute (`after`, `before`, `append`, `prepend`, `modify`, `remove`, `replace`), which only
  an extension can;
- in TypeScript, declares an extension: `interface X extends Y {}` together with `class X {}`.

A screen of your own (`XX301000/XX301000.html` with its `.ts` and `views.ts`) belongs beside the screen and is left
alone, and so is the stock `src/screens` tree, which [AISI0003](AISI0003.md) covers.

## Wrong

```text
SO301000/
  SO301000_AISI.html
  SO301000_AISI.ts
```

## Right

```text
SO301000/
  extensions/
    SO301000_AISI.html
    SO301000_AISI.ts
```

## Turning it off

This is about the file itself, so it's switched off per file: `<!-- muilint-disable AISI0017 -->` in HTML or
`// muilint-disable AISI0017` in TypeScript, anywhere in it. Or per folder in `.editorconfig`:

```ini
[*.{html,ts}]
dotnet_diagnostic.AISI0017.severity = none
```
