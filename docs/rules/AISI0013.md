# AISI0013: Malformed config.bind

**Severity:** error

`config.bind` is a binding expression, usually an object literal with the control's settings. If a brace, bracket,
parenthesis or quote isn't closed, the expression can't be parsed, and the control doesn't get its settings.

MuiLint only checks that everything is balanced. It doesn't check which keys a control accepts, since that needs
the control schemas.

## Wrong

```html
<qp-grid id="grid-Lines" view.bind="Transactions" config.bind="{ allowInsert: false"></qp-grid>
```

## Right

```html
<qp-grid id="grid-Lines" view.bind="Transactions" config.bind="{ allowInsert: false }"></qp-grid>
```

## Turning it off

Once, above the offending line:

```html
<!-- muilint-disable-next-line AISI0013 -->
```

For the whole file, anywhere in it: `<!-- muilint-disable AISI0013 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0013.severity = none
```
