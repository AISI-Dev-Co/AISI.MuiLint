# AISI0003: Stock src/screens path

**Severity:** error

`FrontendSources/screen/src/screens` is Acumatica's own tree. It gets overwritten on upgrade, and publishing from
there collides with the product HTML. Your screens and extensions belong in `src/development/screens` while you work,
and in `src/customizationScreens/<Project>` once they're part of a customisation project.

This one is about where the file lives, so it's reported on line 1 and there's nothing to fix inside the file: move it.

## Wrong

```text
FrontendSources/screen/src/screens/SO/SO301000/extensions/SO301000_Custom.html
```

## Right

```text
FrontendSources/screen/src/development/screens/SO/SO301000/extensions/SO301000_Custom.html
```

If you point `muilint` at the whole `src` folder you'll get this for every stock file. Point it at `development/screens` or `customizationScreens` instead.

## Turning it off

This is about the file itself, so it's switched off per file, with `<!-- muilint-disable AISI0003 -->` anywhere in it, or per folder in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0003.severity = none
```
