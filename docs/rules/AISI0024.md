# AISI0024: Selector matches more than one element

**Severity:** warning

A merge selector (`after`, `before`, `append`, `prepend`, `modify`, `remove`, `replace`) that matches more than one
element of the stock screen. MuiLint counts `[name='X']`, `#id` and `#id [name='X']` against the stock HTML; anything
more complicated isn't counted. Narrow it with the container's id.

## Wrong

```html
<!-- Status is in fsColumnA-Order and in fsTotals-Order -->
<field name="UsrStage" after="[name='Status']"></field>
```

## Right

```html
<field name="UsrStage" after="#fsColumnA-Order [name='Status']"></field>
```

## Source

- [Reusing of UI Definitions: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_UIDefinitionReuse_GeneralInfo.md): "If more than one item satisfies the specified CSS selector, the build process fails."

## Turning it off

Once, above the offending line: `<!-- muilint-disable-next-line AISI0024 -->`. For the whole file, anywhere in it:
`<!-- muilint-disable AISI0024 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0024.severity = none
```
