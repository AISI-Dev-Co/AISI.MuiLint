# AISI0016: View created from a class that isn't a PXView

**Severity:** warning

`createSingle` and `createCollection` take a view class, one that extends `PXView`. Given anything else, usually the
extension class itself, the view isn't built from a view class. Declare a view class, or pass the class you're
extending.

## Wrong

```ts
export interface SOLine_AISI extends SOLine {}
export class SOLine_AISI { UsrPriority: PXFieldState; }

export class SO301000_AISI {
	ExtraLines = createCollection(SOLine_AISI);
}
```

## Right

```ts
ExtraLines = createCollection(SOLine);
```

## Source

- [UI Definition in HTML and TypeScript: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_UIDefinition_GeneralInfo.md): "you define a view class for each view of the graph … The class extends the `PXView` class."
- [UI Customization Development: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_Customization_GeneralInfo.md): an extension can "Initialize new data views in the same way as you do in the screen class."

## Turning it off

Once, above the offending line: `// muilint-disable-next-line AISI0016`. For the whole file: `// muilint-disable AISI0016`. For a
whole folder, in `.editorconfig`:

```ini
[*.ts]
dotnet_diagnostic.AISI0016.severity = none
```
