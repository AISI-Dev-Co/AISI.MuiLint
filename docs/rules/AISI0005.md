# AISI0005: Empty qp-fieldset

**Severity:** suggestion

A `qp-fieldset` with nothing in it, that nothing later in the file adds to. Usually something was meant to go in it
and didn't.

Acumatica's own screens leave fieldsets empty on purpose, so these are left alone: hidden ones (`class="hidden"`),
`wg-container` ones, ones with `modify`/`remove`/`replace`, and ones a later element in the file appends to.

## Flagged

```html
<qp-fieldset id="fsAISI" after="#fsColumnB-Order" view.bind="Document"></qp-fieldset>
```

## Fine

```html
<qp-fieldset id="fsAISI" after="#fsColumnB-Order" view.bind="Document"></qp-fieldset>
<field append="#fsAISI" name="UsrPriority"></field>
```

## Source

- [UI Adjustments in HTML and TypeScript: HTML Examples](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_AdjustmentInExtension_HTML.md): no rule against empty fieldsets; this is a hint, not a documented error, which is why it's a suggestion.

## Turning it off

Once, above the offending line: `<!-- muilint-disable-next-line AISI0005 -->`. For the whole file, anywhere in it:
`<!-- muilint-disable AISI0005 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0005.severity = none
```
