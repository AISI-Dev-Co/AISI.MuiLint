# AISI0026: @gridConfig without a preset

**Severity:** suggestion

Every grid's view class should name a preset in `@gridConfig` (`GridPreset.Primary`, `Inquiry`, `Processing`,
`Details`, ...). A suggestion rather than a warning: grids without one still work, and most of Acumatica's own 24R1
grids predate presets.

## Wrong

```ts
@gridConfig({ syncPosition: true })
export class RSSVWorkOrderItem extends PXView { }
```

## Right

```ts
@gridConfig({ preset: GridPreset.Details, syncPosition: true })
export class RSSVWorkOrderItem extends PXView { }
```

## Source

- [Table (Grid): Configuration of the Table and Its Columns](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDevRef_Grid_Configuration.md): "For each table, you must specify a preset in the preset property of the gridConfig decorator."
- [Form Layout: Grid Presets](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_DesigningLayout_GridPresets.md): "You should use presets because they unify the appearance of grids in the UI and simplify the process of updating the design."

## Turning it off

Once, above the offending line: `// muilint-disable-next-line AISI0026`. For the whole file: `// muilint-disable AISI0026`. For a
whole folder, in `.editorconfig`:

```ini
[*.ts]
dotnet_diagnostic.AISI0026.severity = none
```
