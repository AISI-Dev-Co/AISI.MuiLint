# AISI0007: Extension HTML without a TypeScript file

**Severity:** error

Modern UI doesn't pick up extension HTML on its own. It's loaded through the TypeScript extension with the same
name, so `SO301000_AISI.html` needs an `SO301000_AISI.ts` beside it. Without one, the HTML is never merged, and nothing
tells you.

Only checked by the CLI and the VSIX, which can see the folder. The Roslyn analyser can't read other files.

## Wrong

```text
extensions/
  SO301000_AISI.html
```

## Right

```text
extensions/
  SO301000_AISI.html
  SO301000_AISI.ts
```

## Turning it off

This is about the file itself, so it's switched off per file, with `<!-- muilint-disable AISI0007 -->` anywhere in it, or per folder in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0007.severity = none
```
