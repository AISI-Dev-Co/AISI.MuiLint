# AISI0002: after/before name selector defined in this file

**Severity:** error

The merge applies your extension to the **stock** screen HTML. A selector like `after="[name='UsrPriority']"` is
looked up in the stock markup, and `UsrPriority` isn't in there; you're adding it three lines up. The selector matches
nothing and the element quietly goes missing.

Anchor every `after`/`before` on something the stock screen has. To put two new fields next to each other, anchor
both on the same stock field, or wrap them in a new `qp-fieldset` and anchor that.

## Wrong

```html
<field name="UsrPriority" after="[name='OrderDate']"></field>
<field name="UsrRush" after="[name='UsrPriority']"></field>
```

## Right

```html
<field name="UsrPriority" after="[name='OrderDate']"></field>
<field name="UsrRush" before="[name='CustomerID']"></field>
```

## Turning it off

Once, above the offending line:

```html
<!-- muilint-disable-next-line AISI0002 -->
```

For the whole file, anywhere in it: `<!-- muilint-disable AISI0002 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0002.severity = none
```
