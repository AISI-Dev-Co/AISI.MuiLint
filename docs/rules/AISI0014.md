# AISI0014: Half an extension

**Severity:** warning

A Modern UI extension in TypeScript comes in two halves with the same name. The interface says what you're extending,
and the class says what you're adding:

```ts
export interface SOLine_AISI extends SOLine {}
export class SOLine_AISI {
    UsrNote: PXFieldState;
}
```

Leave one half out, or let the names drift apart, and it still compiles. Nothing is added, though, and the field you
declared never reaches the view.

MuiLint flags an interface with no class of the same name beside it. It also flags a class that extends nothing, has
no interface, and declares fields, actions or views. A plain helper class is left alone. Only files under
`extensions/` are checked.

## Wrong

```ts
export interface SOLine_AISI extends SOLine {}
export class SOLineAISI {
    UsrNote: PXFieldState;
}
```

## Right

```ts
export interface SOLine_AISI extends SOLine {}
export class SOLine_AISI {
    UsrNote: PXFieldState;
}
```

## Turning it off

Once, above the offending line:

```ts
// muilint-disable-next-line AISI0014
```

For the whole file, anywhere in it: `// muilint-disable AISI0014`. For a whole folder, in `.editorconfig`:

```ini
[*.ts]
dotnet_diagnostic.AISI0014.severity = none
```
