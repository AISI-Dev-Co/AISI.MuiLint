# AISI0003: Stock src/screens path

**Severity:** error

`FrontendSources/screen/src/screens` holds Acumatica's own screen sources. Your new screens and your extensions belong
in `src/development/screens`: a customization project picks them up from there, and publishing and unpublishing leave
them alone.

Don't edit `src/customizationScreens` by hand either. The system writes `customizationScreens/<Tenant>` when it
publishes a customization project for a tenant, and deletes it when the project is unpublished.

## Wrong

```text
FrontendSources/screen/src/screens/SO/SO301000/extensions/SO301000_AISI.html
```

## Right

```text
FrontendSources/screen/src/development/screens/SO/SO301000/extensions/SO301000_AISI.html
```

## Source

- [UI Definition in HTML and TypeScript: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_UIDefinition_GeneralInfo.md): "You'll find the Modern UI source code of original Acumatica ERP forms in the `FrontendSources\screen\src\screens` folder".
- [Modern UI Development: Creating Modern UI Source Files for Custom and Customized Forms](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_ModernUI_DevelopmentFolder.md): "The source files of the forms that you create or customize in this folder aren't affected by system operations, such as the publishing and unpublishing of customization projects."
- [Customization Project with UI Changes: How UI Customization Works](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_CustomizationProject_HowWorks.md): "When a customization project … is unpublished for a particular tenant, the system removes the `Scripts\Screens\<Tenant Name>` and `customizationScreens\<Tenant Name>` folders."

## Turning it off

This one is about the file itself, so it's switched off per file: `<!-- muilint-disable AISI0003 -->` in HTML (or
`// muilint-disable AISI0003` in TypeScript), anywhere in it. Or per folder in `.editorconfig`:

```ini
[*.{html,ts}]
dotnet_diagnostic.AISI0003.severity = none
```
