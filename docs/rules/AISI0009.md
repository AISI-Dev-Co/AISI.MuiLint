# AISI0009: Selector target not in stock HTML

**Severity:** warning

MuiLint finds the stock screen for your extension (for
`src/development/screens/SO/SO301000/extensions/X.html` that's `src/screens/SO/SO301000/SO301000.html`), reads every
`name` and `id` in it, follows its `qp-include`s, and checks the `[name='…']` and `#id` parts of your selectors
against them. Whatever any other extension of the screen adds counts too: the stock screen's own `extensions`
folder, `development/screens`, and every project under `customizationScreens`. A miss is nearly always a typo, or a
field that was renamed in an upgrade.

It's a warning rather than an error because a target can still come from somewhere MuiLint can't see. If that's the
case, suppress it on that line.

It stays quiet when there's no stock file to compare against, or when an include can't be followed, since a partial
picture would only produce false alarms. Only the CLI and the VSIX run it.

## Wrong

```html
<field name="UsrWeight" before="[name='OrderDat']"></field>
```

## Right

```html
<field name="UsrWeight" before="[name='OrderDate']"></field>
```

## Turning it off

Once, above the offending line:

```html
<!-- muilint-disable-next-line AISI0009 -->
```

For the whole file, anywhere in it: `<!-- muilint-disable AISI0009 -->`. For a whole folder, in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0009.severity = none
```
