# AISI0004: Extension named as the parent screen

**Severity:** warning

Acumatica names extension files `<ScreenID>_<postfix>`, such as `SO301000_AISI.html` and `SO301000_AISI.ts`. A
`SO301000.html` in `SO301000/extensions/` is named like the screen it extends, and its TypeScript would clash: the
extension's interface would be `SO301000 extends SO301000`.

## Wrong

```text
SO301000/extensions/SO301000.html
```

## Right

```text
SO301000/extensions/SO301000_AISI.html
```

## Source

- [UI Customization Development: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_Customization_GeneralInfo.md): "Each file name starts with the screen ID and ends with a postfix that indicates the purpose of the extension".
- [Updating a Customization Project for the Modern UI: General Information](https://github.com/Acumatica/Acumatica-AI-Resources/blob/2026R1/Documentation/DeveloperGuide/UIDev_Customization_Convert_GeneralInfo.md): "The file names follow this structure: `<screenID>_<customizationProjectName>` (for example, `IN202500_PhoneRepairShop`)."

## Turning it off

It checks `.html` files only. It applies to the whole file, so switch it off per file with
`<!-- muilint-disable AISI0004 -->` anywhere in it, or per folder in `.editorconfig`:

```ini
[*.html]
dotnet_diagnostic.AISI0004.severity = none
```
